Entry for the [One Letter: Coffee or Tea](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0)
competition on [make.fun](https://make.fun).

The entry is exactly one letter: **A for coffee**. `main.ts` (Node 22, stdlib
only, deterministic, no network) writes that single letter — one byte, no
trailing newline — to `/output/entry.txt`, then reads it back to verify it is
exactly the one character the gate requires.

Run it with:

```sh
node main.ts
```
